# Research decision register

Baseline: October 8, 2026. Run: `verified-companies-2026-10-08`. Confirmed from the saved configuration and implementation.

Documented baseline; proposal fields do not change the app or saved run.

Decision-affecting research policy, operational bounds, optional source routes and measured outputs. UI layout/download formatting limits are outside this research-policy register.

Flow: 1 · Set scope → 2 · Verify sources → 3 · Collect inventory → 4 · Preserve evidence → 5 · Decide eligibility → 6 · Extract statements → 7 · Human review → 8 · Assess and compare → 9 · Report and audit

Every editable ID has a blank **Proposed change** cell. Edit that cell or send IDs with the desired value. Measured outputs are read-only. Raising/lowering applies to numeric limits; broadening/tightening applies to rules.

Compute: pipeline execution is local Python; network sources run employer/ATS infrastructure. Optional Codex inference is remote through the configured account. Current run made zero model calls. CPU utilization, peak RAM, GPU activity, token counts and dollar cost are not measured.

Important differences to review: unknown seniority passes entry/mid collection but is excluded from shares; Workday stored filters are not applied by the current collector; approving every extracted statement counts as reviewed without a separate omission audit; collector pending-extraction counters can become stale after independent extraction.
